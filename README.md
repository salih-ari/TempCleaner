# TempCleaner

**TempCleaner** is an Android application built with Kotlin and Jetpack Compose that scans temporary and cache files to help free up storage space, with user permission.

## Features

- **Temporary File Cleaning:** Scans and organizes temporary and cache files by category.
- **User Control:** Allows users to review and select specific files before deletion.
- **Modern UI:** Built with Jetpack Compose and Material 3, featuring smooth navigation and customizable themes.
- **Multi-Language Support:** Available in English, Turkish, and Spanish.
- **Dependency Injection:** Uses Dagger Hilt for a clean and maintainable architecture.

## Tech Stack

| Technology | Description |
| --- | --- |
| Kotlin | Programming language |
| Jetpack Compose | Modern declarative UI toolkit |
| Material 3 | UI components and design system |
| Navigation Compose | Screen navigation |
| Dagger Hilt | Dependency injection |
| MVVM | Application architecture |

## Screens

- **Home:** Overview of storage information and cleaning categories.
- **Scan Results:** Displays scanned files grouped by category.
- **Delete Confirmation:** Provides a confirmation step before deleting selected files.
- **Settings & Theme:** Allows users to customize preferences, themes, and language.
- **About:** Displays application version and project information.
